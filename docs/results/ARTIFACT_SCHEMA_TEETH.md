# Artifact schema teeth — what is refused, and what that costs

Static night shift, ITEM 2. Companion to
`docs/results/STATIC_AUDIT_RUNTIME_RECOVERY.md`, which recorded the defect
(BC-5) this closes.

## The rule

**Position on disk is not identity.** A result may depend on a JSON artifact
only if the artifact states, inside itself, which experiment it belongs to and
which arm it is — and only if that agrees with the path it was found at.
Absence of a declaration is a refusal, not a default.

This is a strictly earlier question than admissibility. `result_loader.py` asks
*is this evidence eligible*; `artifact_schema.py` asks *is this file the thing
we think it is*. A document can pass every check in the new module and still be
VOID.

## What was added

`tools/artifact_schema.py` — a kind registry plus `validate()`,
`declaration_reasons()` and `load_checked()`. Registered in
`tools/run_safe_tests.py` as **NO_CONTACT**: it reads `docs/results/` and
nothing else, opens no socket, starts no process.

Four kinds are declared: `RUNTIME_MEMORY_ARM`, `RUNTIME_MEMORY_RESULTS`,
`RM_BACKEND_CONTINUITY`, `RC_QWEN_BLOCK_LABEL`.

An artifact is refused when it:

| refusal | why it matters |
|---|---|
| declares no `experiment_id` | anonymous evidence |
| declares a *different* experiment | the wrong file at the right path |
| declares an arm that disagrees with its filename | content/location skew |
| is missing `samples` / `problems` / `windows` | the fields consumers hard-index |
| has `samples` of the wrong type, or empty | an iteration that discovers row 40 is malformed at row 40 |
| has any sample row missing `backend_pids` | the exact `KeyError` BC-5 described |
| declares `ks`, `kh` or `n` different from 1.8 / 20 / 3 | see below |
| has a non-object root, or is not parseable JSON | crash converted to refusal |

**The freeze is enforced, not chosen.** The `FROZEN` block does not decide
ks/kh/n. It refuses an artifact that *declares values different from the
preregistration*. Enforcing a freeze and setting one are not the same act, and
no threshold was touched by this item.

## Consumers rewired to refuse instead of crash

- `backend_continuity.py` — `read_arms()` replaces `json.load` +
  `d["samples"]`. A refusal is fatal for the whole `--apply` run: a partial
  roll-up over the arms that happened to parse is a worse artifact than none.
  Its own output now declares itself (`artifact_kind`, `experiment_id`,
  `produced_by`) and is validated against its own schema before writing.
- `qwen_fossil_admissibility.py` — both inputs go through `load_checked`.
  This mattered most for `RUNTIME_MEMORY_RESULTS.json`, which is read entirely
  through `.get()` defaults: any JSON file with the right keys would previously
  have been scored as a RUNTIME-MEMORY result. Refusal fails closed, which for
  this tool means the block stays quarantined.
- `result_loader.py` — identity is now checked before eligibility, and an
  unparseable file is refused rather than raised on.

## The cost, stated plainly

**`backend_continuity.py --apply` can no longer produce a roll-up from the
artifacts currently on disk, and this is committed knowing that.**

All four `RUNTIME_MEMORY_*.json` files predate the current writer. They carry no
`experiment_id`, no `run_kind`, no `integrity_status`. Under the new schema all
four are refused, `--apply` prints the refusals and exits 1 without writing.
The existing `RM_BACKEND_CONTINUITY.json` is left untouched — it is now also
protected by an overwrite guard, since superseded evidence is amended rather
than replaced.

That is the correct outcome, and it is the same fact RM-1 established from the
other direction: **no arm has ever been executed against the corrected
harness.** The tooling now says so out loud instead of computing a witness over
inputs whose provenance nobody checked.

The refusal is asserted as a test, not left to inspection. If those four files
are ever regenerated by a corrected harness, `backend_continuity --selftest`
and `artifact_schema --selftest` will both flip to FAIL and demand the tests be
re-read. A green test that would stay green after the world changed is not a
witness.

## Nothing was rewritten

No artifact on disk was edited, regenerated or deleted. No threshold, seed set,
gate verdict rule or acceptance criterion was changed. The old-schema arm
artifacts remain exactly as they were, now refused rather than misread.

## Sabotage discipline used here

Every refusal in `artifact_schema --selftest` is proven by mutation, and each
mutation **asserts that it applied** before the refusal is checked. A sabotage
that silently failed to apply is a green test that proves nothing. 29 checks:
one positive control (a well-formed artifact is admitted — without it every
refusal below would be vacuous), 14 mutation sabotages, and the on-disk
refusals above.
